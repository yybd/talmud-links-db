# גרף הקישורים של הש"ס

מאגר נגזר: **מי דן במה** בתלמוד הבבלי — קישורים בין שורות ודיבורי־המתחיל
של מפרשים, כמסד SQLite אחד. הריפו מחזיק את **הארטיפקט ואת מה שבונה
אותו**; האפליקציה שצורכת אותו יושבת במקום אחר.

## הורדה

```bash
curl -sL -o links-manifest.json \
  https://github.com/yybd/talmud-links-db/releases/latest/download/links-manifest.json
curl -sL -o links.db.zst \
  https://github.com/yybd/talmud-links-db/releases/latest/download/links.db.zst
zstd -d links.db.zst -o links.db
```

**המניפסט קודם.** הוא כמה מאות בייטים ונושא `otzariaDbVersion`,
`schema`, `size` ו-`sha256`; המסד הוא ~82MB. אין סיבה להוריד את השני
כדי לגלות שאין חדש. `manifest/latest.json` שבריפו הוא אותו קובץ,
והיסטוריית הגיט שלו היא היסטוריית הגרסאות.

## מה יש בפנים

| טבלה | מה |
|---|---|
| `link` | קישור בין שתי שורות, עם סוג הקשר |
| `line_ref` | מזהה שורה → ספר, מספר שורה, ומראה מקום |
| `line_dh` | דיבורי־המתחיל, בצורה מנורמלת לחיפוש |
| `daf_line` | שורות הגמרא, מפורקות לדף ולעמוד |
| `book`, `connection_type` | שמות ספרים, וסוגי קשר: פירוש, עין משפט, מסורת הש"ס, תרגום ועוד |

**אין כאן טקסט.** הגרף יודע מי דן ואיפה זה כתוב, לא מה כתוב שם. את
הטקסט עצמו שולפים מהמקורות. המספרים המדויקים לכל גרסה נמצאים ב-PR
שפרסם אותה.

## העדכון — אוטומטי עד הלחיצה האחרונה

```
אוצריא מפרסמת db_version חדש
        │
        ▼  check-upstream (יומי)   ← שולף 80 בייט ומשווה. רוב הימים נגמרים כאן.
        │
        ▼  בונה: מוריד 1.4GB, פורס, גוזר את הגרף, אורז ל-82MB
        │
        ├─ ריליס **טיוטה** — releases/latest אינו רואה אותו
        └─ PR שמעדכן את manifest/latest.json, משויך לך
        │
        ▼  אתה ממזג  ← זה האישור
        │
        ▼  publish-on-merge הופך את הטיוטה לפרסומה ומאמת
```

**למה לא פרסום אוטומטי.** אוצריא מפרסמת אוטומטית כי זה המוצר שלה; כאן
זו נגזרת, ומסד חדש מגיע ללומדים. הדיף שאתה מאשר *הוא* האישור.

הבנייה עולה כדקה (נמדד על runner: הורדה 9 שניות, פריסה 18, בנייה 12,
דחיסה 27), והבדיקה היומית עולה שניות.

## בנייה מקומית

```bash
python3 tools/check_upstream.py                         # יש חדש באוצריא?
python3 tools/build_links_db.py                         # מהתקנת אוצריא שבמק
python3 tools/publish.py --tag v<תאריך>-otzaria<גרסה>   # אורז; --upload מפרסם
```

## מאין זה נגזר

המקור הוא [`Otzaria/SeforimLibrary`](https://github.com/Otzaria/SeforimLibrary) —
מסד הספרים של [אוצריא](https://github.com/Otzaria/otzaria). כל ריליס
כאן נגזר מריליס אחד שלהם, ו-`otzariaDbVersion` אומר מאיזה.

הנתונים שם נאספו מ-Sefaria, דיקטה, ויקיטקסט, תורת אמת, בן-יהודה
ותא שמע. **לחלק גדול מהספרים אין רישיון מוצהר במקור**, ולכן מה שמפורסם
כאן הוא הגרף בלבד — קישורים ומראי מקום, שהם עובדות על טקסטים — ולא
הטקסטים עצמם. מסד המקור המלא אינו משוכפל לכאן, במכוון.

## סכימה

`meta.schema` הוא מספר הסכימה. צרכן שאינו מכיר אותו **אמור לסרב
להתקין**: מסד עם סכימה עתידית ייפתח יפה ויחזיר תוצאות ריקות בשקט, וזו
תקלה שאי אפשר לאבחן.

| schema | מה השתנה |
|---|---|
| 2 | ‏`line_dh` נושא `dhNorm`/`dhTight` מנורמלים; `dhText` הוסר |
| 1 | הראשון |

⚠️ **הנרמול הוא חוזה בין שני ריפואים.** `tools/dh_match.py` צורב את
`dhNorm` לתוך המסד, והלקוח מנרמל את הקטע בזמן ריצה באותה צורה בדיוק.
פער ביניהם אינו מתפוצץ — הוא גורם לחיפוש למצוא פחות, בשקט. **כל שינוי
כאן מחייב הרצת מבחן הזהות שבצד הלקוח.**
