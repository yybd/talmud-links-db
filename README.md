# גרף הקישורים של הש"ס

מאגר נגזר: **מי דן במה** בתלמוד הבבלי — 1,816,659 קישורים בין שורות,
ו-1,159,997 דיבורי-מתחיל של מפרשים, כמסד SQLite אחד.

הריפו הזה מחזיק **רק את הארטיפקט**. הקוד שבונה אותו והאפליקציה
שצורכת אותו יושבים במקום אחר; כאן יש ריליסים בלבד.

## מה יש בפנים

| טבלה | שורות | מה |
|---|---|---|
| `link` | 1,816,659 | קישור בין שתי שורות, עם סוג הקשר |
| `line_ref` | 1,174,545 | מזהה שורה → ספר, מספר שורה, ומראה מקום |
| `line_dh` | 1,159,997 | דיבורי-המתחיל, בצורה מנורמלת לחיפוש |
| `daf_line` | 81,586 | שורות הגמרא, מפורקות לדף ולעמוד |
| `book` | 7,367 | שמות הספרים |
| `connection_type` | 23 | פירוש, עין משפט, מסורת הש"ס, תרגום, ועוד |

**אין כאן טקסט.** הגרף יודע מי דן ואיפה זה כתוב, לא מה כתוב שם. את
הטקסט עצמו שולפים מהמקורות.

## הורדה

```bash
curl -sL -o links-manifest.json \
  https://github.com/yybd/talmud-links-db/releases/latest/download/links-manifest.json
curl -sL -o links.db.zst \
  https://github.com/yybd/talmud-links-db/releases/latest/download/links.db.zst
zstd -d links.db.zst -o links.db
```

**המניפסט קודם.** הוא כמה מאות בייטים ונושא `otzariaDbVersion`,
`schema`, `size` ו-`sha256`; המסד הוא 82MB. אין סיבה להוריד את השני
כדי לגלות שאין חדש.

## מאין זה נגזר

המקור הוא [`Otzaria/SeforimLibrary`](https://github.com/Otzaria/SeforimLibrary) —
מסד הספרים של [אוצריא](https://github.com/Otzaria/otzaria). כל ריליס
כאן נגזר מריליס אחד שלהם, ו-`otzariaDbVersion` שבמניפסט אומר מאיזה.

הנתונים שם נאספו מ-Sefaria, דיקטה, ויקיטקסט, תורת אמת, בן-יהודה
ותא שמע. **לחלק גדול מהספרים אין רישיון מוצהר במקור**, ולכן מה שמפורסם
כאן הוא הגרף בלבד — קישורים ומראי מקום, שהם עובדות על טקסטים — ולא
הטקסטים עצמם.

## סכימה

`meta.schema` הוא מספר הסכימה. צרכן שאינו מכיר אותו **אמור לסרב
להתקין**: מסד עם סכימה עתידית ייפתח יפה ויחזיר תוצאות ריקות בשקט, וזו
תקלה שאי אפשר לאבחן.

|---|---|

| 1 | הראשון |
